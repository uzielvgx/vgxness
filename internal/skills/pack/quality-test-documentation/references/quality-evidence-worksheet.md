# Quality evidence worksheet

Use after framing the decision. It plans evaluation; it does not execute or certify verification.

| Item | Record | Evidence or unknown |
| --- | --- | --- |
| Scope | Product/version, decision, owner | |
| Evidence and risks | Requirement/interface/risk source and affected users | |
| Coverage | Test level, case or exploratory charter, expected observation | |
| Conditions | Environment, data, access, dependency, control | |
| Evidence | Artifact, provenance, evaluator, retention | |
| Criteria | Observable entry/exit criteria and residual risk | |
| Maintenance | Change trigger, review owner, stale-coverage check | |

Traceability supports review, not a claim that every requirement is verified or that quality/compliance is assured.
