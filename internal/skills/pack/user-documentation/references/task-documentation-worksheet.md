# Task documentation worksheet

Use after identifying the audience and task. This is a writing and review aid, not a substitute for product evidence.

| Item | Record | Evidence or unknown |
| --- | --- | --- |
| Audience and goal | Who performs what task and why | |
| Form | Tutorial, how-to, reference, or explanation; why | |
| Scope | Product/version, entry point, prerequisites, permissions | |
| Flow | Ordered steps and observable checkpoints | |
| Result and recovery | Expected result; known failure and safe recovery | |
| Inclusion | Structure, alternatives, terms, locale/translation owner | |
| Maintenance | Owner, source, publication, review trigger | |

Use Diátaxis as conditional guidance: select the form that matches the user need. WCAG concepts may inform inclusive content review, but do not claim conformance without qualified evidence.
