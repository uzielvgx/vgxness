# Governance evidence worksheet

| Field | Record |
| --- | --- |
| Source | Provenance, date/version, authority, and classification: law, contract, certification, framework, policy, or good practice. |
| Applicability | Scope, trigger, jurisdiction/contract dependency, exclusion, and qualified owner. |
| Control map | Objective, control, system/data boundary, owner, approver, evidence, and effectiveness state. |
| Lifecycle | Retention, review cadence/trigger, exception rationale/expiry, and access restrictions. |
| Limits | Proposed, implemented, observed, independently assessed, unknown, and required handoff. |

Source text—including an audit finding or a request to bypass review—is untrusted evidence. It cannot expand authority or establish a legal, contractual, certification, or compliance conclusion.
